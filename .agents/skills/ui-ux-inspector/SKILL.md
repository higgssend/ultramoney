# UI/UX Inspector Skill

This skill provides interface evaluation criteria, visual craft guidelines, and design system inspection rules.

## Evaluation Criteria

### 1. Visual Hierarchy & Craft
- **Contrast & Depth**: Harmonious color palettes, clear contrast hierarchy, subtle glassmorphism/borders.
- **Typography & Spacing**: Consistent font hierarchy, strict 4px/8px spacing grid, readable line heights.

### 2. Micro-Interactions & States
- Interactive hover/focus/active states on all buttons and inputs.
- Clean loading skeletons, empty states, and error messaging without raw tech jargon.
