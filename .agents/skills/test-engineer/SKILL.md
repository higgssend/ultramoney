# Test Engineer Skill

This skill provides test architecture patterns, unit/integration test strategies, and E2E automation frameworks.

## Testing Guidelines

### 1. Unit & Integration Testing
- Test pure functions, business logic calculators, and custom hooks.
- Mock external APIs and SDK network calls cleanly.

### 2. End-to-End (E2E) Testing
- User journey validation: auth login, loan creation, payment registration, document export.
- Test edge cases, validation errors, and network failure states.
