# NIST Compliance Skill

This skill provides guidelines and control mappings based on the NIST Cybersecurity Framework (CSF 2.0) and NIST SP 800-53 security controls.

## NIST CSF 2.0 Core Functions

### 1. Govern (GV)
Establish organizational cybersecurity governance, risk management policy, and legal compliance boundaries.

### 2. Identify (ID)
Asset management, risk assessment, and understanding system components, data flows, and threats.

### 3. Protect (PR)
- **Access Control (PR.AA)**: Enforce authentication, authorization, and least privilege.
- **Data Security (PR.DS)**: Protect data at rest and in transit via encryption.
- **Platform Security (PR.PS)**: Patch management, secure configuration, and system hardening.

### 4. Detect (DE)
- Continuous security monitoring, logging, and intrusion detection.

### 5. Respond (RS)
- Incident management, containment, communication, and mitigation.

### 6. Recover (RC)
- Disaster recovery, backups, and restoration of normal operations.
