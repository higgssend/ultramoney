# Git Reviewer Skill

This skill provides guidelines for inspecting Git commit structures, pull requests, and version control history.

## Standards

### 1. Conventional Commits
- Enforce strict commit formatting: `feat:`, `fix:`, `docs:`, `refactor:`, `style:`, `test:`, `chore:`.
- Ensure single atomic commits per feature or fix.

### 2. PR Review & Conflict Management
- Check diff size, verify merge safety, and generate clean release changelogs.
