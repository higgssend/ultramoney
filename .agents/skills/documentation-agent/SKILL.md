# Documentation Agent Skill

This skill provides templates and technical writing standards for project documentation.

## Deliverables

### 1. Project README & Architecture
- Clear setup instructions, environment variables, technology stack, and architecture overview.
- Mermaid sequence & component DFD diagrams.

### 2. JSDoc & API Specifications
- Precise JSDoc parameter/return annotations for utility functions and hooks.
- Endpoint specs detailing method, parameters, sample JSON payloads, and error codes.
