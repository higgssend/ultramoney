# Refactor Expert Skill

This skill provides step-by-step refactoring workflows, design patterns, and architectural principles.

## Principles

### 1. SOLID Principles
- **Single Responsibility**: Each module/class does one thing well.
- **Open/Closed**: Open for extension, closed for modification.
- **Liskov Substitution / Interface Segregation / Dependency Inversion**.

### 2. DRY & KISS
- Eliminate duplicate code branches without over-engineering abstract wrappers.
- Favor clear, simple imperative/declarative logic over clever one-liners.
